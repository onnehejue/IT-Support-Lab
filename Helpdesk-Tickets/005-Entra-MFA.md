# 005 — Enable per-user MFA in Microsoft Entra

- **Type:** Retrospective lab account-security request.
- **Account:** Sarah Williams, test user.
- **Priority:** Normal (illustrative).
- **Status:** Completed — per-user MFA status enabled.
- **SLA:** Not measured; timings not recorded.

## Task and actions

Opened the per-user MFA page from Microsoft 365 administration. Selected Sarah's account and enabled MFA. The page displayed an enablement confirmation. Refreshed the list because it initially still showed disabled; the final row showed **enabled**.

## Resolution and verification

The administrative status change was verified in the refreshed list. This does not establish MFA method registration, an enforced status, a successful MFA challenge or Conditional Access policy configuration.
